# Python Quiz App :- 
This is a simple command-line Quiz Application built using Python. The application presents users with multiple-choice questions and allows them to select an answer for each question.

The quiz contains questions from different general knowledge topics, with four options provided for every question. The program checks the user's answer, displays whether it is correct, and keeps track of the score throughout the quiz. At the end, the user's final score is displayed based on the total number of correct answers.

## Features :-
* Multiple-choice quiz questions
* Four answer options for each question
* Instant feedback for correct answers
* Score tracking throughout the quiz
* Final score displayed at the end
* Simple and beginner-friendly command-line interface

## Concepts Used :-
* Python functions
* Lists and dictionaries
* Loops
* Conditional statements
* `enumerate()`
* User input handling
* String methods

**This project was created to practice basic Python programming concepts and understand how to work with lists, dictionaries, loops, functions, and user input while building a simple interactive application.**
